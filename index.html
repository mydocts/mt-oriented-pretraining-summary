ALMA: A Paradigm Shift in Machine Translation Guo et al. MT-oriented adaptation 2024-02 ICLR 2024 LLaMA-2-7B / LLaMA-2-13B；另用 MPT-7B 做部分对照。 两阶段训练：Stage 1 对非英语与英语单语语料做 CLM 继续训练；Stage 2 用少量高质量平行数据做翻译指令微调。 严格说 Stage 1 更像 monolingual full fine-tuning / pre-SFT adaptation，不是典型“继续预训练 + 指令无关语料”的 CPT。 单语：OSCAR；平行：WMT 2017-2020 test sets、FLORES-200 dev/test，开发/测试还用 WMT 2021/2022。 主要依赖 curated / human-written 的 WMT 与 FLORES 高质量数据；单语采样按语言比例控制，未看到额外复杂清洗细节。
  • Stage 1：LLaMA-2-7B 最多 20B 单语 tokens；13B 最多 12B tokens；论文显示 1B tokens 已有明显收益。
  • Stage 2：约 58K 平行样本，2 epochs。
  • 单语语言采样比例：de/cs/is/zh/ru/en = 20/14/8/19/22/17%。
 WMT 2021 is↔en；WMT 2022 cs/de/zh/ru↔en；另评估 XNLI、XStoryCloze、XWinograd 等跨语言能力。 sacreBLEU、COMET-22。
Tower: An Open Multilingual LLM for Translation-Related Tasks Alves et al. general MT CPT 2024-02 COLM 2024 LLaMA-2-7B / LLaMA-2-13B。 在 LLaMA-2 上做 translation-oriented continued pretraining 得到 TowerBase，再做指令微调得到 TowerInstruct；CPT 使用 next-token prediction，混合单语与平行数据。 单语：mC4，覆盖 en/de/fr/nl/it/es/pt/ko/ru/zh；平行：OPUS100、WikiMatrix、News-Commentary、TildeModel、Bible 等公开平行语料。 单语采用 CCNet / LLaMA 风格清洗；平行数据用 Bicleaner 与 COMETKiwi-22 质量过滤。 20B tokens；约 2/3 单语 + 1/3 平行。 FLORES-200、WMT23、TICO-19；并评估 APE 与其他 translation-related tasks。 COMET-22 为主；另报告 BLEU、chrF、XCOMET、COMETKiwi、BLEURT 等。
LLaMAX: Scaling Linguistic Horizons of LLM by Enhancing Translation Capabilities Beyond 100 Languages Lu et al. massively multilingual CPT 2024-07 / 2024-11 Findings EMNLP 2024 LLaMA-2-7B、LLaMA-3-8B；instruction 对齐版本使用 Alpaca 风格数据。 在 LLaMA 系列上做大规模 multilingual continual pretraining，目标是把翻译能力扩展到 FLORES-101 覆盖的 100+ 语言；核心分析包括是否扩展词表、如何做低资源数据增强、以及单语和平行数据如何组织。 单语：mC4、MADLAD-400，覆盖 102 语言；平行：Lego-MT 102 语言、4,737 language pairs；低资源增强使用 MUSE、PanLex 字典构造 pseudo-parallel data。 论文强调保留原始 LLaMA vocabulary，避免新增 token 破坏原模型分布；低资源语料通过字典覆盖率与 pseudo-parallel 构造增强。具体通用清洗阈值未展开。 continual pretraining 使用超过 64B tokens；LLaMAX2 训练约 60 天。平行句对按 source-target 拼接成单条训练序列。 FLORES-101、FLORES-200；另有 WMT23、TED、TICO，以及 XNLI、MGSM、MMLU 等多语泛化评估。 spBLEU、COMET；多语理解/推理任务使用对应 accuracy 等指标。
Enhancing Translation Accuracy of LLMs through Continual Pre-Training on Parallel Data Kondo et al. parallel-data CPT 2024-08 IWSLT 2024 rinna/bilingual-gpt-neox-4b；另与 Transformer encoder-decoder、Direct-SFT 等比较。 用英日平行数据做 CLM continued pretraining；比较 Mono、En-Ja、Ja-En、Mix，以及 interleaved / prefixed / tagged / JSON 等格式；之后做少量 SFT。 JParaCrawl v3.0 英日平行语料；SFT 使用 WMT20 dev/test、FLORES-200、KFTT 等。 用 LEALLA-large 语义相似度从 JParaCrawl 中采样高质量对；保留相似度约 0.4-0.95 的句对以剔除不合适样本。
  • CPT：20.8M 句对，1 epoch，context length 2048。
  • Mix 设置：10.4M En-Ja + 10.4M Ja-En。
  • SFT：每方向约 15K 样本。
 13 个英日测试集，包括 ASPEC、JESC、KFTT、TED/IWSLT、BSD、WMT Robustness、WMT22 GMT 等。 sacreBLEU、COMET-22，并做显著性检验。
Multilingual MT with Open LLMs at Practical Scale: An Empirical Study GemmaX2 parallel-first CPT 2025-02 NAACL 2025 Long 主要 backbone 为 Gemma2-9B；对比 Mistral-7B-v0.3、Qwen2/2.5-7B、LLaMA3/3.1-8B、Gemma2-2B 等。 提出 PFMS：Parallel-First Monolingual-Second。每种语言优先使用平行数据，不足部分用单语补足；平行句按 source-target 或 target-source 拼接并随机方向训练。 单语：CulturaX、MADLAD-400；平行：OPUS 中英中心与英语中心语料，收集至 2024-08。 平行数据去重、启发式过滤、fastText 语言识别、LaBSE 与 MuSR 语义相似度过滤；保留相似度 0.75-0.99。单语数据使用已清洗/审核版本。
  • 28 种语言；清洗后约 3.4B 句对。
  • 目标为每语言 2B tokens；低资源语言可能不足。
  • SFT 约 196K 平行样本。
 FLORES-200、WMT-24。 FLORES：spBLEU、COMET；WMT-24：XCOMET-XXL、COMETKiwi；另分析 tokenizer length ratio。
X-ALMA: Plug & Play Modules and Adaptive Rejection for Quality Translation at Scale Xu et al. modular MT CPT 2025-03 ICLR 2025 Spotlight ALMA-13B-Pretrain / LLaMA-2-13B；训练语言专属 LS Modules，每个模块约为基座参数的 15%。 三阶段 pre-training：Stage 1 训练基座多语能力；Stage 2 冻结基座、用单语数据训练语言组 LS modules；Stage 3 用平行句拼接成 pseudo-monolingual 序列继续训练 LS modules；后续 SFT 与 ARPO。 Stage 1/2：OSCAR 单语；Stage 3：NLLB、OPUS 平行语料；SFT：FLORES-200 dev、NTREX、WMT 2015-2022 test data。 -
  • Stage 1：50 语言、20B 单语 tokens。
  • Stage 2：每个 LS module 10B 单语 tokens。
  • Stage 3：每个 LS module 1.25B pseudo-monolingual tokens。
  • SFT：每方向约 3K-7K，平均约 4K。
 FLORES-200、WMT23。 COMET-22 为主；附录报告 XCOMET-XL、BLEU。
Tower+: Bridging Generality and Translation Specialization in Multilingual LLMs Alves et al. large-scale MT CPT 2025-06 arXiv / Technical Report Gemma 2 9B 为主要消融 backbone；发布/对比 2B、9B、72B Tower+ 系列，并与 Qwen2.5 等比较。 CPT 使用 next-token prediction；混合单语、平行与 instruction-like 数据。平行数据被格式化为翻译指令模板。CPT 后将 translation-specialized checkpoint 与原基座做 checkpoint merge，再进入 SFT、WPO、RLVR。 单语：FineWeb-Edu；平行：主要 OPUS；文档级：EuroParl、ParaDocs、CosmoPedia-v2；instruction-like：从 FineWeb-Edu 通过 DSIR 采样。 单语用 EuroFilter-v1；平行用 COMETKiwi adequacy 过滤；instruction-like 数据用 DSIR 贴近高质量 instruction 数据分布。 32B tokens；27 种语言/方言，47 个语言对；66% 单语 + 33% 平行 + 1% instruction-following。 WMT24++、IF-MT、M-ArenaHard、IFEval。 WMT24++ 主指标 XCOMET-XXL；另报告 MetricX24-XXL、chrF；IF-MT 分 MT quality 与 instruction following。
Massively Multilingual Adaptation of LLMs Using Bilingual Translation Data / EMMA-500 Gen 2 Ji et al. bilingual-data CPT 2025-06 arXiv / Technical Report LLaMA-3-8B、LLaMA-3.1-8B；发布 EMMA-500 Llama 3/3.1 Mono/Bi 四个模型。 研究 massively multilingual continual pretraining 中加入 bilingual translation data 的影响；构造 monolingual mix 与 bilingual mix 对照，使用 causal LM objective 继续训练 LLaMA 3 系列。 MaLA bilingual translation corpus：OPUS、NLLB、Tatoeba 等来源，覆盖 500+ 语言、2,507 language pairs；同时混合 cleaned/deduplicated MaLA 单语语料、事实/百科/代码/指令等多类型数据。 语言/脚本识别、语言代码规范化、dataset-specific cleaning、去重；处理 Tatoeba 等语料中的重复/噪声句对；按资源等级做统计和采样。
  • MaLA translation corpus 清洗后超过 426B tokens。
  • Mono mix：25K steps，约 419B LLaMA-3 tokens。
  • Bi mix：40K steps，最多 671B tokens。
 7 类任务、12 个 benchmarks；低资源重点包括 FLORES-200、SIB-200、Taxi1500 等。 MT 使用 FLORES-200 对应翻译指标；其他任务报告分类、推理、阅读理解等 benchmark 分数。当前抽取文本中未见统一单一 MT 指标名称。
Seed-X: Building Strong Multilingual Translation LLM with 7B Parameters Cheng et al. from-scratch MT pretraining 2025-07 arXiv / Technical Report 从头预训练的 7B Seed-X base；后续发布 instruct model、RL model 和 reward model。 三阶段预训练：S1 general stage 使用主流语言大规模单语数据；S2 multilingual-dominant stage 提高多语单语和双语数据比例；S3 parallel-only stage 用多轮重写/过滤后的高质量双语数据继续训练。之后做 translation SFT 与 PPO-based RL。 单语：28 语言共 6T tokens；双语：先从公开 web data 收集约 200B tokens seed bilingual data，再用临时翻译模型翻译、改写、过滤，迭代生成更高质量 pseudo/parallel data。 单语用文档级质量评估模型分 high/medium/low 三档：高质量保留、中质量用 LLM paraphrase、低质量剔除；双语用语言识别置信度、word alignment 指标、多轮 LLM filtering/rewriting 和 poor-quality pair filtering。
  • 单语预训练数据：6T tokens。
  • seed bilingual data：约 200B tokens。
  • SFT：236K translation-only instruction instances。
 FLORES-200 756 directions、WMT-25 English-to-X 25 target languages、Seed-X-Challenge；另有内部 ZH↔EN 测试。 XCOMET-XL、BLEURT；表格中也报告 COMET/BLEURT，RL 阶段避免直接用 BLEU/BLEURT/COMET 作 reward。
Hunyuan-MT Technical Report Tencent Hunyuan Team industrial MT pretraining 2025-09 arXiv / Technical Report Hunyuan-7B-Base；产出 Hunyuan-MT-7B 与 Hunyuan-MT-Chimera-7B。 训练流程为 general pre-training → MT-oriented pre-training → SFT → RL → weak-to-strong RL。MT-oriented 阶段混合单语与双语语料，并用 RegMix 类似方法确定最优混合比例；加入 20% 原始预训练语料 replay 缓解遗忘。 General pretraining：1.3T tokens 多语语料，覆盖 112 种语言/方言；MT-oriented：单语 mC4、OSCAR；双语 OPUS、ParaCrawl 等公开平行语料。 单语：fastText 语言识别、minLSH 文档去重、KenLM 困惑度质量过滤；双语：CometKiwi 等 reference-free QE 过滤。General pretraining 还用自研质量评估模型做 Knowledge Value / Authenticity / Writing Style 打分与分类配比。
  • General pretraining 多语部分：1.3T tokens。
  • MT-oriented pretraining 具体总 token 与单/双语比例未在当前片段中给出。
  • 原始预训练语料 replay：20%。
 FLORES-200、WMT24pp、WMT2025 shared task、Mandarin⇔Minority translation。 XCOMET-XXL；后续 SFT/RL 还使用 CometKiwi、GEMBA/DeepSeek-V3 evaluator 等质量信号。
From Unaligned to Aligned: Scaling Multilingual LLMs with Multi-Way Parallel Corpora Liu et al. multi-way parallel CPT 2025-11 EMNLP 2025 Main LLaMA-3.1-8B / LLaMA-3.1-8B-Instruct；Qwen-2.5-14B / Qwen-2.5-14B-Instruct；LoRA 训练。 用 multi-way parallel TED2025 做 continued pretraining，并与 unaligned multilingual CPT 做固定 token 规模对照；还研究 MT、CLTS、MTC、CLP 等 instruction-tuning objectives。 Aligned：TED2025，多语 TED Talks，113 语言、352 domains、最多 50-way parallel、4,765 language pairs；Unaligned：DCAD-2000。 TED2025 基于人工验证 TED 翻译与人工时间戳做句级对齐；论文用 COMET-QE 比较数据质量；未看到额外过滤阈值。 主对照固定 CPT 为 5M tokens；规模实验采样 10K 到 1B tokens。 MMMLU、XCOPA、FLORES-101、FLORES-200、xIFEval、SIB-200；另分析 32 aligned languages 的表征对齐。 Accuracy；BLEU、COMET；cosine similarity、CKA、retrieval P@1/P@5/P@10、SVCCA；COMET-QE 用于数据质量分析。
HY-MT1.5 Technical Report Tencent Hunyuan Team compact MT pipeline 2025-12 arXiv / Technical Report HY-1.8B-Base、HY-7B-Base；产出 HY-MT1.5-1.8B-preview、HY-MT1.5-7B、HY-MT1.5-1.8B。 沿用 Hunyuan-MT 的 MT-oriented pretraining + SFT；完整 pipeline 为 MT-oriented pretraining → SFT → on-policy distillation → RL。1.8B 通过 7B teacher 做 strong-to-weak on-policy distillation。 MT-oriented 阶段引用 Hunyuan-MT 方案：高质量多语单语语料与平行文本；distillation 阶段收集约 1M 单语 samples，覆盖 33 种支持语言。 MT-oriented 阶段细节指向 Hunyuan-MT；distillation 数据清洗未在当前片段中展开。 CPT 总量与单/双语配比未在当前片段中给出；distillation 数据约 1M 单语 samples。 FLORES-200、WMT25、Mandarin⇔Minority Testset。 XCOMET-XXL、CometKiwi。
Omnilingual MT: Machine Translation for 1,600 Languages Omnilingual MT Team omnilingual CPT 2026-03 arXiv / Technical Report OMT-LLaMA 基于 LLaMA-3.1-8B-Instruct；另构建 1B/3B 版本与 OMT-NLLB 路线。 OMT-LLaMA 使用 multilingual continual pretraining + post-training + retrieval-augmented translation；CPT 同时做 monolingual documents 的 language modeling 与 parallel documents 的 translation objective，并扩展 tokenizer 到 256K。 单语：CC-2000-Web、CC-2000-Pdf，覆盖 2000+ 可识别语言；平行：Bible、FLoRes+、SMOL、Indic corpora、KreyolMT、LTPP、MeDLEy 等；还用 backtranslation 和 bitext mining 构造 synthetic data。 URL 过滤低质量网页；GlotLID 识别语言；单语 backtranslation 前抽取 clean monolingual texts 并去噪；synthetic bitext 用相似度阈值和资源等级做过滤消融；MeDLEy 由专业翻译/人工构建。
