变量小结

变量 典型方法
state source GKD 把训练状态移到 student 自生成序列；DistiLLM 用 adaptive off-policy 降低纯 on-policy 成本；Stable-OPD 用 rollout mixture 稳定状态分布
teacher / feedback source GKD/MiniLLM/Revisiting 用 white-box teacher logits；SCOPE 加 correctness / perplexity；MiMo / DeepSeek-V4 用多 teacher；OPRD 用 hidden states
support sampled-token 最便宜但信号弱；Revisiting 用 teacher top-K；DeepSeek-V4 用 full-vocab；OPRD 转到 representation support
KL / update route GKD 是 direct KL/JSD；MiniLLM/vOPD 是 PG-style reverse KL；AOPD 是 sign-conditioned hybrid；EOPD 是 entropy-conditioned KL switch
temporal credit 大多数 OPD 仍是 token-local；vOPD 改 baseline；OPD+ 改 advantage 设计；survey 提出的 GAE-OPD 是未来方向
routing / gating TIP 按 entropy/divergence 选 token；SCOPE 按 correct/incorrect rollout 分流；AOPD 按 advantage sign 切换；EOPD 按 teacher entropy 切 KL
regularizer Stable-OPD 的 reference constraint；vOPD 的 control variate；Revisiting 的 top-k + masking；SCOPE 的 group normalization
evaluation split 最好的 OPD 论文已经不只看平均分，而是拆 correct/incorrect、entropy、top-k overlap、prefix/suffix、length/repetition、teacher-student compatibility 等
